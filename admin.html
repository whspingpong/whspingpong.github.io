Publish your changes

Follow these in order. It takes about two minutes. You cannot break anything permanently, every change can be undone.

What is actually happening here: the website reads all of its text from a single file called data.js. This editor has rewritten that file for you. All you are doing below is replacing the old file with the new one.

Download the new file

Click the button. A file called data.js lands in your Downloads folder.

Downloading is far more reliable than copy and paste, because there is no clipboard to get out of sync. Use this method.

Open the right folder on GitHub

Go to github.com/whspingpong/whspingpong.github.io and sign in.

Click the assets folder, then click the js folder.

You should see admin.js, app.js and data.js listed.

Upload it

Click the Add file button near the top right, then choose Upload files.

Drag the data.js you just downloaded into the box, or click choose your files and pick it from Downloads.

It replaces the old data.js automatically because the name matches. That is exactly what you want.

Save it

Scroll down. Type a short note about what you changed, for example updated this week's training days.

Click the green Commit changes button.

Wait a minute

GitHub needs about a minute to rebuild the site. Grab a drink.

Check that it worked

Click the button below. It reads the live website and tells you whether your changes actually made it.

Then open the site and press Ctrl+Shift+R to force your browser to load the new version instead of the one it remembered.

If something goes wrong

Site looks broken or blank? Nothing is lost. Go to the repo, click Commits, find the commit before yours, and revert it. Then tell Daniel. You cannot permanently break anything.

Uploading new photos

Resize the pictures first

Photos straight off a phone or camera are far too big and will make the site painfully slow. They need to be shrunk first.

Easiest option: send the photos to Daniel and let him run the resizer.

Doing it yourself: put them in the tools/incoming folder and run python tools/add-photos.py, which does everything and prints the lines you need.

Upload the two versions

Each photo needs a large copy in assets/img/photos and a small copy with the same file name in assets/img/thumbs.

On GitHub, open the folder, click Add file, then Upload files, drag the pictures in, then Commit changes. Repeat for the other folder.

Add the row here

Come back to the Photos tab in this editor, click Add a photo, and type the file name without the .jpg on the end.

So state-final.jpg is entered as just state-final.

Then publish again using steps 1 to 6 above.

The file, if you prefer copy and paste

Downloading is safer, but if you would rather paste by hand: open assets/js/data.js on GitHub, click the pencil, press Ctrl+A then Delete, then paste this in.
