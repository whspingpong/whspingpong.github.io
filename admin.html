Publish your changes

Follow these in order. It takes about two minutes. You cannot break anything permanently, every change can be undone.

What is actually happening here: the website reads all of its text from a single file called data.js. This editor has rewritten that file for you. All you are doing below is replacing the old file with the new one.

Copy the new file

Click the button below. That copies the whole file to your clipboard.

If the button does not work, click into the black box below, press Ctrl+A then Ctrl+C.

Open the file on GitHub

Go to the club's repository on github.com and sign in.

Click the assets folder, then the js folder, then click data.js.

Not signed in, or you do not see a pencil icon in step 3? Then you do not have edit access yet. Ask Daniel to add you as a collaborator on the repo.

Start editing

Near the top right of the file there is a row of small icons. Click the pencil icon.

The file becomes an editable text box.

Replace everything

Click anywhere inside the text box, then press Ctrl+A to select the entire file.

Press Delete. The box should now be completely empty.

Press Ctrl+V to paste in the new version.

On a Mac use Cmd instead of Ctrl.

Save it

Click the green Commit changes... button at the top right.

A box pops up. Type a short note about what you changed, for example updated this week's training days. Leave everything else alone.

Click the green Commit changes button in that box.

Check the site

Wait about one minute, then open the website and press Ctrl+Shift+R to force it to reload.

Your changes should be there.

Site looks broken or blank? Do not panic, nothing is lost. Go back to the repo, click Commits, find the commit before yours, and revert. Then tell Daniel.

Uploading new photos

Resize the pictures first

Photos straight off a phone or camera are far too big and will make the site painfully slow. They need to be shrunk first.

Easiest option: send the photos to Daniel and let him run the resizer.

Doing it yourself: put them in the tools/incoming folder and run python tools/add-photos.py, which does everything and prints the lines you need.

Upload the two versions

Each photo needs a large copy in assets/img/photos and a small copy with the same file name in assets/img/thumbs.

On GitHub, open the folder, click Add file, then Upload files, drag the pictures in, then Commit changes. Repeat for the other folder.

Add the row here

Come back to the Photos tab in this editor, click Add a photo, and type the file name without the .jpg on the end.

So state-final.jpg is entered as just state-final.

Then publish again using steps 1 to 6 above.
